# 📌 About the Project

Modern project management platforms are no longer simple task trackers.

They now leverage Artificial Intelligence to automate workflows, generate insights, prioritize work, summarize documents, and improve team collaboration.

**Kroolo** is one such enterprise SaaS platform that combines:

- Artificial Intelligence
- Project Management
- Team Collaboration
- Workflow Automation
- REST APIs
- Mobile Applications
- Third-party Integrations

As a QA Engineer, my responsibility was to validate the quality, reliability, usability, security, and performance of the application across multiple platforms.

---

# 🎯 Business Objectives

The testing strategy focused on validating that Kroolo delivers reliable and secure AI-powered collaboration.

Key objectives included:

✔ Validate AI-powered task creation and recommendations
