# Kroolo – AI-Powered Project Management & Collaboration Tool

## 📌 Project Overview
Kroolo is an AI-enabled project management and collaboration platform designed to improve team productivity through intelligent automation, AI-driven insights, and seamless integrations with tools like Jira, Slack, and Asana.

This project focuses on **end-to-end quality assurance** of Kroolo across **Web, Mobile, and API layers**, ensuring functional accuracy, integration reliability, security, performance, and usability.

---

## 🎯 Objectives
- Validate AI-driven project and task workflows
- Ensure seamless collaboration across Web & Mobile platforms
- Verify automation rules and third-party integrations
- Validate API reliability and data consistency
- Ensure secure access, role-based permissions, and performance stability
